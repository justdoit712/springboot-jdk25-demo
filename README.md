这是一个基于 **JDK 25** 和 **Spring Boot 3.x** 的现代化 Java 后端学习项目。

## 特性说明
- 全面拥抱最新的 Java 语言特性（记录类、模式匹配、虚拟线程等）。
- 底层全面迁移至 Jakarta EE 标准。
- 采用 Multi-Module 多模块架构，方便各个功能解耦学习。

## 开发环境
- JDK 21 / 25
- Maven 3.9+
- Spring Boot 3.3+

## 如何开始
本项目为多模块工程，各个子模块（如 `demo-helloworld`）会在后续学习中逐步添加。
你可以在 IDEA 中直接打开本项目的根目录来开始你的学习之旅。
