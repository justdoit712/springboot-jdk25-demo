# Spring Boot JDK 25 Demo

这是一个基于 **JDK 25** 和 **Spring Boot 3.x** 的现代化 Java 后端学习项目。

## 特性说明
- 全面拥抱最新的 Java 语言特性（记录类、模式匹配、虚拟线程等）。
- 底层全面迁移至 Jakarta EE 标准。
- 采用 Multi-Module 多模块架构，方便各个功能解耦学习。

## 开发环境
- JDK 21 / 25
- Maven 3.9+
- Spring Boot 3.3+

## 模块说明
- [demo-01-helloworld](./demo-01-helloworld): Spring Boot 3 & JDK 25 基础运行与 Hello World
- [demo-02-properties](./demo-02-properties): Spring Boot 配置文件与 `@ConfigurationProperties` 使用
- [demo-03-exception-handler](./demo-03-exception-handler): 全局异常处理机制（`@RestControllerAdvice`）
- [demo-04-actuator](./demo-04-actuator): Spring Boot Actuator 监控端点基础
- [demo-04-actuatorpro](./demo-04-actuatorpro): Spring Boot Actuator 高级应用与定制
- [demo-05-mybatis](./demo-05-mybatis): 集成 MyBatis 进行数据库访问
- [demo-06-mybatis-plus](./demo-06-mybatis-plus): 集成 MyBatis-Plus 进行高效数据库访问
- [demo-07-upload](./demo-07-upload): 本地文件上传功能演示

## 如何开始
本项目为多模块工程，各个子模块会在后续学习中逐步添加。
你可以在 IDEA 中直接打开本项目的根目录来开始你的学习之旅。
