A modern Java backend learning project based on **JDK 25** and **Spring Boot 3.x**.

## Features
- Fully embraces the latest Java language features (Records, Pattern Matching, Virtual Threads, etc.).
- The underlying layer is fully migrated to the Jakarta EE standard.
- Adopts a Multi-Module architecture for easy decoupling and learning of various functions.

## Development Environment
- JDK 21 / 25
- Maven 3.9+
- Spring Boot 3.3+

## Modules Overview
- [demo-01-helloworld](./demo-01-helloworld): Basic Spring Boot 3 & JDK 25 setup and Hello World
- [demo-02-properties](./demo-02-properties): Spring Boot configuration and `@ConfigurationProperties` usage
- [demo-03-exception-handler](./demo-03-exception-handler): Global exception handling with `@RestControllerAdvice`
- [demo-04-actuator](./demo-04-actuator): Basics of Spring Boot Actuator monitoring endpoints
- [demo-04-actuatorpro](./demo-04-actuatorpro): Advanced Spring Boot Actuator applications and customization
- [demo-05-mybatis](./demo-05-mybatis): Integrating MyBatis for database access
- [demo-06-mybatis-plus](./demo-06-mybatis-plus): Integrating MyBatis-Plus for efficient database access
- [demo-07-upload](./demo-07-upload): Local file upload functionality demonstration

## Getting Started
This project is a multi-module project. Various sub-modules will be gradually added during the learning process.
You can directly open the root directory of this project in IDEA to begin your learning journey.
