A modern Java backend learning project based on **JDK 25** and **Spring Boot 3.x**.

## Features
- Fully embraces the latest Java language features (Records, Pattern Matching, Virtual Threads, etc.).
- The underlying layer is fully migrated to the Jakarta EE standard.
- Adopts a Multi-Module architecture for easy decoupling and learning of various functions.

## Development Environment
- JDK 21 / 25
- Maven 3.9+
- Spring Boot 3.3+

## Getting Started
This project is a multi-module project. Various sub-modules (such as `demo-helloworld`) will be gradually added during the learning process.
You can directly open the root directory of this project in IDEA to begin your learning journey.
